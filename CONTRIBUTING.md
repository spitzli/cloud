You retain your copyright. Unless explicitly stated otherwise, intentional
contributions to Apache-licensed code are submitted under Apache-2.0. Include the
provenance and existing license of third-party code; do not submit code you lack
permission to contribute. Component-specific licenses remain in effect.

Never include credentials, customer data or production database exports in a contribution. Use the repository's owned disposable fixtures for verification.
