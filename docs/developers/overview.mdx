Spitzli Cloud has a native Rust Core, a React Console and independently released plugins. Core owns identity, workspaces, project access, encrypted provider connections, scheduling and deployment authorization. Start with the interface for your task.

| Task | Interface | Credential |
| --- | --- | --- |
| Automate a workspace | Workspace API and installed plugin actions | Workspace API token |
| Send transactional email | Mail REST API | Restricted Mail API key |
| Automate customer/project inventory | Registry REST API | OAuth token with registry scopes |
| Use registry, hosting or installed plugin tools | MCP | Registered OAuth client and matching scopes |
| Connect a CMS | Website SSO and protected bridges | Registered website integration |
| Develop a runtime plugin | Independent plugin repository and SDK | Private runtime enrollment managed by Core |

Keep decimal platform IDs as strings. Keep credentials server-side. Check an operation's final state before retrying a mutation; an accepted request is not a completed deployment.

For platform contributions, use [local development](/developers/local-development). The canonical source is [spitzli/cloud](https://github.com/spitzli/cloud). The local checkout and existing package names may still use `webdock`; registered protocol addresses retain their existing names.
