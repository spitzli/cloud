title: "Plan and usage"
description: "Check configured workspace limits, resource reservations and reported usage."
---

Open your workspace's **Plan and usage** page in [Console](https://console.spitzli.cloud). It shows the assigned plan, configured allowances, reserved resources and available usage samples.

## Understand what is shown

| Value | Meaning |
| --- | --- |
| Workspace limit | A configured allowance for the workspace |
| Reserved resources | Capacity assigned to services, which can include retained storage |
| Reported usage | Observed consumption for services that report telemetry |
| No workspace plan | No plan is assigned; service-specific restrictions may still apply |
| Unreported usage | No usable telemetry is available; it does not mean zero consumption |

Operators configure plans and customer-specific overrides. Availability also depends on the service's own permissions, capacity and limits. A plugin installation or plan assignment does not provision infrastructure.

## Request a change

Ask your operator to review the relevant allowance when a resource action is blocked. Before reducing a limit, review active services and retained data. Stopping an application or deleting its configuration can leave storage allocated.

There is no universal free resource quota promised by this documentation. Use the limits shown for your workspace. A missing workspace limit does not remove provider quotas or service restrictions.

## Provider billing

Your own Neon, turboSMTP and Vercel accounts retain their provider charges and quotas. A provider connection does not transfer billing to Spitzli Cloud or cancel subscriptions.

Console does not currently include built-in checkout, subscription management or invoice summaries. Any existing external billing arrangement remains separate.
