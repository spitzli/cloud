Open Mail in the intended workspace. Connections, domains, keys and message history are scoped to that workspace's permissions.

| Task | Required service |
| --- | --- |
| Send transactional messages | Ready sending connection, Mail API key and verified sender domain |
| Receive or forward incoming messages | Explicitly enabled incoming-mail service |
| Use your own sending provider | Activated turboSMTP connection and its separate limits |

Sending-only does not require a mailbox server. Adding a sender domain does not create mailboxes. Incoming mailboxes and forwarding are activated separately and only for eligible workspaces.

## Prepare API sending

<Steps>
  <Step title="Select a connection">Open Mail in the correct workspace and select the intended ready connection.</Step>
  <Step title="Add your domain">Use a domain you control. Copy the exact verification records shown.</Step>
  <Step title="Publish DNS">Add those records at your DNS provider and request verification. Review existing SPF and other mail records before changing them.</Step>
  <Step title="Create a sending key">Restrict the application key to the intended domain where appropriate. Store it in your application's private environment.</Step>
</Steps>

Continue with [your first API message](/developers/mail-quickstart) and the [Mail API overview](/developers/mail-api).

<Note>API implementation, production dispatch and provider event callbacks have separate activation checks. Use the readiness shown for your connection and confirm availability with your operator before relying on delivery.</Note>

## Manage incoming Mail

Ask your operator to confirm incoming-mail availability before configuring mailboxes or forwarding. Use the DNS records and settings shown for that service. Outgoing API readiness does not establish that incoming delivery or Webmail is ready.

Disabling incoming Mail retains its data. Permanent deletion is a separate action. During service draining, existing resources remain manageable while creation of new accounts, domains and mailboxes is blocked.

For customer-owned sending, follow [Connect your turboSMTP account](/guides/byok-mail).
